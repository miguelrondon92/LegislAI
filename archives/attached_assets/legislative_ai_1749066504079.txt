AI Legislative Analysis Platform Development Prompt
Core Vision
Build a complete AI-powered legislative analysis platform with an MCP (Model Context Protocol) server backend that democratizes understanding of complex congressional bills. The system should instantly parse, categorize, and evaluate legislation while providing personalized insights based on user policy preferences.

Technical Architecture Requirements
MCP Server Backend
Implement a lightweight MCP server that exposes modular tools for legislative analysis
Each capability should be exposed as a discrete, API-like tool that can be easily integrated into AI agents or interfaces
Tools should include: bill parsing, section categorization, stakeholder mapping, policy alignment scoring, and alert generation
Use modern Python framework (FastAPI recommended) with proper async handling
Include comprehensive error handling and logging
Core Functionality Tools
Bill Parser Tool

Input: Bill number/ID or Congress API URL
Process: Fetches from api.congress.gov, handles XML/HTML/PDF text formats
Extracts structured data: sections, subsections, amendments, funding allocations
Cross-references with bill metadata (sponsors, committees, status)
Returns standardized JSON format with full provenance tracking
Policy Categorizer Tool

Uses LLM to categorize bill sections into policy domains (healthcare, environment, economy, etc.)
Identifies controversial or high-impact provisions
Tags sections with confidence scores and reasoning
Stakeholder Mapper Tool

Maps bill sections to affected stakeholder groups
Identifies winners/losers for each provision
Cross-references with lobbying data when available
Alignment Scorer Tool

Accepts user policy profiles (JSON format with weighted preferences)
Scores each bill section against user values (-100 to +100 scale)
Generates detailed explanations for alignment/conflict reasoning
Alert Generator Tool

Creates prioritized alerts based on policy conflicts or alignments
Supports multiple alert types: email summaries, push notifications, detailed reports
Includes actionable insights and contact information for relevant representatives
User Interface Components
Clean, modern web interface for exploring bill analysis
User profile creation for policy preferences (sliders, weighted categories)
Interactive bill viewer with section-by-section breakdowns
Dashboard showing personalized alerts and trending legislation
Comparison tools for multiple bills or versions
Data Integration
Primary Data Source: https://api.congress.gov/ for real-time congressional bill data
Implement comprehensive Congress API client with endpoints for:
Bill search and retrieval (/bill/{congress}/{billType}/{billNumber})
Bill text in multiple formats (/bill/{congress}/{billType}/{billNumber}/text)
Bill actions and status updates (/bill/{congress}/{billType}/{billNumber}/actions)
Committee information (/committee)
Member information (/member)
Amendment tracking (/amendment)
Support for uploading custom legislative documents as fallback
Historical bill database populated from Congress API for trend analysis
Optional integration with lobbying disclosure data from senate.gov

Congress API Integration Requirements
API Setup & Authentication

Obtain API key from https://api.congress.gov/sign-up/
Implement proper rate limiting (1000 requests/hour for registered users)
Add User-Agent header with contact information as required by API terms
Core API Endpoints to Implement

# Bill retrieval and search
GET /bill                           # Search bills with filters
GET /bill/{congress}/{billType}/{billNumber}     # Get specific bill
GET /bill/{congress}/{billType}/{billNumber}/text # Get bill full text
GET /bill/{congress}/{billType}/{billNumber}/actions # Get bill actions/status
GET /bill/{congress}/{billType}/{billNumber}/amendments # Get amendments

# Supporting data
GET /member                         # Congress member information  
GET /committee                      # Committee information
GET /committee/{chamber}/{committeeCode}/bills # Bills by committee

Sample User Workflows
Citizen Advocate: Searches for "climate change" bills, platform automatically fetches latest environmental legislation from Congress API, sets up profile prioritizing environmental protection, receives alerts when new climate bills are introduced with detailed analysis of how provisions align with their values

Policy Researcher: Inputs bill number "HR-1234", system fetches all versions and amendments from api.congress.gov, uses comparison tools to track changes over time, identifies what lobbying groups may have influenced revisions, exports detailed reports

Legislator's Office: Sets up monitoring for bills from specific committees, receives daily briefings on new legislation from Congress API, analyzes constituent impact of proposed legislation, generates talking points for public communications

Lobbyist/Advocacy Group: Configures alerts for bills containing specific keywords, gets instant notifications when relevant legislation is introduced, analyzes bill text against client interests, tracks amendment activity in real-time
